# Release notes

## 0.4.3 (build 8) - tidy-up
- Removes the leftover "(test build)" wording from the main screen. No other changes from 0.4.2.

## 0.4.2 (build 7) - superseded by 0.4.3
- Paste TikTok's full share text (link plus words and extra links): the app finds the video link by itself.
- Smaller install, about 24 MB instead of 39 MB.

## 0.4.1 (build 6) - superseded by 0.4.2
- Fixes a crash on first launch that affected fresh installs of 0.4.0 (uninstall 0.4.0, then install this).
- If the app ever stops unexpectedly, the next launch shows what went wrong so it can be reported.
- Confirmed on a real phone: TikTok, Instagram, Snapchat, Facebook, X, YouTube, Pinterest, Reddit and Threads.

## 0.4.0 (build 5) - withdrawn
- Crashed on first launch on some phones. Use 0.4.1.

## 0.3.1 (build 4) - tested build, not published
- History screen no longer sits against the status bar.

## 0.3.0 (build 3)
- Download history screen with Open and Share.

## 0.2.0 (build 2)
- New launcher icon, link detection for nine sites, Open and Share after a download, share links in
  from other apps, daily automatic yt-dlp updates, smaller release build (about 21 MB).

## 0.1.0 (spike)
- First working TikTok download on-device.

## First public release (draft)
- Signed with the permanent release key. If you installed a test build, uninstall it once before
  installing this one.
- Source for this release: the git tag matching the version number.
- Verify your download: the APK's SHA-256 and the signing certificate fingerprint are listed with the release.
