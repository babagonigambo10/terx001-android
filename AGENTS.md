# AGENTS.md

Instructions for any AI agent or contributor working on this repository.

1. Read `HANDOFF.md` first, completely, before doing anything. It has the project state, stage status,
   the owner's decisions, hard rules and the next step.
2. Obey the hard rules in `HANDOFF.md` section 5. In short: the repo stays private; no signing keys,
   secrets, publishing, store submissions, channel posts or bot changes without the owner's explicit approval.
3. Keep `HANDOFF.md` updated: after every commit, and immediately whenever you think you are close to a
   usage or context limit. Update the stage table, "Last action and next step", and open items.
4. When only documentation changed, add `[skip ci]` to the commit message so GitHub Actions does not rebuild.
5. Never claim a download or feature works unless the owner has confirmed it on their phone.
